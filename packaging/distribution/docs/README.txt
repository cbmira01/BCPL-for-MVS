BCPL FOR MVS 3.8J - DISTRIBUTION NOTES
=======================================

BCPL is a programming language. This project rebuilds a BCPL
environment for IBM System/370 running MVS 3.8J.

Start here:
  INSTALL   How installation will work
  DATASETS  Library names and what they contain
  COMPILE   How BCPL programs are built
  VERIFY    How to check a working installation
  RELEASE   Project status and release information
  LICENSE   Copyright and redistribution notes

Today the working compiler is the demoted Cambridge compiler.
It runs as INTCODE under ICINT19 and produces System/370 assembly.
The separate native Cambridge compiler is still being rebuilt.

Project source and full guides:
  https://github.com/cbmira01/BCPL-for-MVS

This is draft documentation. No AWS tape release is claimed here.
