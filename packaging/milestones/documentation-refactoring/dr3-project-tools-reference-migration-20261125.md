## Findings and reconciliation obligations

- DSPAL status --probe is a real IEFBR14 submission, not merely an endpoint check. The standalone reconstruction plan --probe is a different read-only operation. The earlier reconstruction manual describes the former as a probe but should be clarified during reconciliation; no existing manual changed in this batch.
- DSPAL's initbcpl route does not expose the core module's internal --raw parser option. Use the dispatched executable contract, not internal parser options.
- The two assembler generators have different input and output arguments and listing defaults. Do not silently translate historical helper syntax into current executable syntax.
- job-summary default maximum successful RC is 4; required zero-RC and assembler/semantic gates are independent.
- compile-mvs preview unlinks an existing selected output before rendering. This source-observed limitation is retained without fixing software.
- Source-local documentation contains pre-M3 aliases, old object inventories, stale probe and device acceptance wording. Existing contracts and historical records are preserved; current actual interfaces and later acceptance govern the distinctions in the draft.
- The release driver can return zero for a declined run. No-retry intent and result evidence, not RC alone, control whether a production attempt was consumed.
- This is principal-interface coverage, not exhaustive clause-level API reconciliation of every diagnostic helper, environment variable or error path. DR.0 dependency qualification and DR.5 validation obligations remain. No target execution, host execution of actual repository tests, new source-identity comparison against historical target receipts or raw private MVS evidence inspection was performed.

The approved chapter sequence is retained. The catalog update links a substantive working reference and does not transfer normative authority or supersede the existing release how-to. No source, test, JCL, config, registry, manifest, release artifact or accepted evidence was changed.
