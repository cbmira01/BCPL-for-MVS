## Interpreted Core Runtime and representation

ICINT19 assembles and executes INTCODE, using aligned fullword backing and BCPL word pointers (host address / 4). Application memory and loaded code/workspace share the 40001-word PROGVEC allocation; 700 separate global words span G!0–699. This is capacity, not available stack size. G!54/G!55 supplied for Cambridge hosting do not make MR10's other globals or calling convention native-compatible. No universal arbitrary address safety: OP1 store guard checks program/global ranges; it is not a general read, byte or pointer bounds checker.

ICLIB deck binds machine services G!6 (CHANGECO), 11–14 (select input/output, RDCH/WRCH), 30–32 (STOP, LEVEL, LONGJUMP), 40–42 (APTOVEC, FINDOUTPUT, FINDINPUT), 46–47 (ENDREAD/ENDWRITE), 85–86 (GETBYTE/PUTBYTE). G!7–10 are local coroutine state/scratch, not four extra callable exports. The ICLIB deck does not implement native G!15 UNRDCH or G!26 SKIPREC; the separate corrected Cambridge BOOTHOST accommodation does not change this MR10 contract. Historical declarations for REWIND, NEWPAGE or WRITEARG do not prove implementation. LEVEL, LONGJUMP and APTOVEC have interpreter-specific source mechanisms (X31/X32/X35); do not import native temporary-vector limits or assert exhaustive standalone execution support. The coroutine-specific X32 continuation behavior remains covered by the approved common contract.

GETBYTE(S,I) reads logical byte I from word S+floor(I/2), even offset high byte of the low 16-bit packed value and odd offset low byte. Result is 0–255. PUTBYTE(S,I,B) writes that packed byte, preserving the other for B in 0–255. ICPUTBY does not mask B to eight bits before OR; therefore require valid byte values, valid nonnegative offset and accessible storage. Do not transfer native PUTBYTE truncation semantics or claim safe writes for arbitrary offsets/values. The [bytes regression](../../../mr10-kit-compiler/tests/00-regression-panel/data-movement/bytes.bcpl) checks four characters across two words; full signed/out-of-domain packing not established. Counted strings store length byte at zero; 255 is the representation limit, not universal buffer capacity.

FINISH returns interpreted zero; STOP(N) selects interpreted CODE N (X30). ICINT19 reports cycles and CODE, invokes MAPSTORE on negative results, closes streams and frees interpreter-owned regions on its ordinary main-end path, and returns MVS RC0 from that path. Do not equate this with native STOP's requested MVS completion code. Source generic interpreter error gives CODE=-1, guarded OP1 address failure gives CODE=-2; neither represents universal abend recovery. Historical BLIBI MAPSTORE prints a not-implemented notice; interpreter-level MAPSTORE is separate diagnostic code, not the native BLIB diagnostic interface. Verify independent JES RCs, CODE and exact outputs, as stated in the [panel notes](../../../mr10-kit-compiler/tests/00-regression-panel/README.md).

## MR10 character-stream contract

The ICLIB X24–X29/X33–X34 interfaces and ICINT19 stream layer are not native BCPLIO. Supported domain: valid allocated uppercase DD names of 1–8 characters, compatible fixed record allocation, known live handles of the intended direction.

- FINDINPUT/FINDOUTPUT convert counted logical ASCII string characters to host EBCDIC, blank-pad to eight characters, check fixed tables (INTIN input; SYSPRINT/INTCODE output), otherwise search live ordinary objects by name and direction. Ordinary descriptors own DCB/buffer and use conditional GETMAIN then RDJFCB before publication. Returned allocation or RDJFCB failure gives zero; no blanket guarantee of recoverable OPEN failure. Repeated lookup of an already-open matching object preserves position by source. FIND is not selection. Unlike native normalization, do not promise lower-case folding. The temporary conversion buffer is 32 host bytes and conversion precedes MAKENAME length checks; arbitrary oversized counted strings are not safe validation inputs.
- SELECTINPUT/SELECTOUTPUT directly store native opaque handle values in interpreter state; no direction/membership validation. These are host descriptor values, not generic BCPL word pointers. Check FIND's zero result; pass only valid live handles of correct direction and do not dereference them. Do not claim native case-193 rejection semantics.
- RDCH returns logical ASCII characters via ETOA translation, all 80 input bytes including padding, followed by synthesized newline (logical 10); no selected input or end-of-data yields -1. EOF is tracked on the descriptor. Do not infer native FB80 right-trimming. WRCH uses ATOE translation; compatible ordinary text output fills FB80, pads partial records and flushes when newline arrives or before storing beyond a full buffer. SYSPRINT uses a 132-character payload with source-managed leading printer-control byte; distinguish logical records from raw JES attribution. With no output selection HOSTWR does nothing. Do not promise raw byte-for-byte record identity, physical printer routing or arbitrary input character coverage.
- ENDREAD closes selected stream and clears input; ENDWRITE flushes selected pending output, closes and clears output. Dynamic CLOSESTR unlinks and FREEMAINs the ordinary object; never use a closed handle, and do not assert nonrecycling or ABA safety. Static streams are separate. Main-end CLOSEALL closes static streams and drains ordinary linked objects; generic pending outputs are flushed by CSGENOUT. Do not claim that every static partial record is flushed (CSSYSPR closes directly). No promise after unexpected system abend or unsuccessful CLOSE.
- INTCODE output is a dedicated token-recordization adapter: suppress CGI slash immediately followed by newline, retain other literal slash, assemble tokens into 80-byte physical records without splitting ordinary tokens, pad and flush on appropriate boundaries. Token buffer cap 80; longer arbitrary tokens not established. Do not generalize this transformation to ordinary text streams or claim source/record identity. Compiler artifact format remains separate authority.

Evidence: [named DD JOB 9543](../../../mr10-kit-compiler/tests/05-named-dd/acceptance-20261104.md), [nested GET JOB 9547](../../../mr10-kit-compiler/tests/06-dynamic-streams/acceptance-20261104.md), [12 live input streams JOB 9548](../../../mr10-kit-compiler/tests/07-many-streams/acceptance-20261104.md) and regular line-io. The 12-stream fixture selects each live handle, reads nine characters, ends read, and verifies output; it does not prove unlimited handles, physical output bytes or failure recovery. DR.5 JOBs 9920/9921 verify specific nested/suppressed GET behavior; compiler options remain separate. [Character translation probe](../../../mr10-kit-compiler/tests/08-character-translation/README.md) is among historical experimental probes, not complete translation certification. No new arbitrary pointer/oversized-name/failed OPEN testing proposed for this supported-domain transfer.

## Historical BLIBI public subset

The exact tracked deck exports 11 global procedures: G!60 WRITES, 62 WRITEN, 63 NEWLINE, 66 PACKSTRING, 67 UNPACKSTRING, 68 WRITED, 70 READN, 75 WRITEHEX, 76 WRITEF, 77 WRITEOCT, 78 MAPSTORE. G!71 TERMINATOR is data referenced by READN. This is tracked deck export census, not installed binary census or automatic regeneration equivalence. Historical source corresponds by signatures and visible algorithm; no claim of independent all-instruction equivalence.

- WRITES emits counted string bytes, NEWLINE emits logical newline, WRITEN calls WRITED with width zero. WRITED emits signed decimal with minimum width and no truncation; it negates negative values, so minimum signed word not guaranteed. WRITEHEX/WRITEOCT emit specified digits by recursive shifts; use positive bounded digit counts. No arbitrary width/all-word boundary proof.
- UNPACKSTRING(S,V) copies length and characters to word vector; PACKSTRING(V,S) writes V!0 low eight bits as length and corresponding characters, clears next unused byte when length even, returns floor(length/2). Caller supplies sufficient readable/writable extents; valid 0–255 byte values; no arbitrary overlap or aliasing guarantee. Do not import native PACKSTRING's four-byte formula.
- READN skips space/tab/newline, reads optional sign then digits, returns accumulated signed result and records consumed nondigit/EOF in TERMINATOR. No-digit result zero; no overflow check or pre-call TERMINATOR initialization promise. Compiler option-reader evidence is not exhaustive MR10 application READN coverage; retain source-derived limitations.
- WRITEF(FORMAT,A,...,K) uses eleven argument words. %S and %C consume one; %N decimal; %I/%X/%O consume a following width character (digit or A–F for normal supported widths); unknown conversion writes its type character. The tracked historical BLIBI does not provide the native %$ skip contract. Require sufficient arguments and valid format bytes. Distinguish interpreted BLIBI WRITEF from the ICINT19 assembler-private reporting WRITEF (%N/%C with three host arguments).
- MAPSTORE in BLIBI writes the historical not-implemented message. Do not advertise native USERPOSTMORTEM, STACKHWM, VALIDPOINTER or interpreter MAPSTORE as BLIBI public capabilities.

Regular [basic-library](../../../mr10-kit-compiler/tests/00-regression-panel/standard-library/basic-library.bcpl) directly covers WRITES, WRITEN, NEWLINE, and WRITEF with ordinary text and numeric output; other regular programs exercise %N/%S/%C. Other procedures remain source-observed unless identified by accepted fixtures. No transfer of unverified full historical API.

## MR10 allocator

[Source](../../../mr10-kit-compiler/library/getvec-freevec.bcpl): HEAPINIT(BASE,WORDS) clears FREEHEAD, refuses null BASE or fewer than three words, otherwise creates one free extent covering the supplied arena. Supply accessible contiguous arena, initialize before use, never reset with live allocations. GETVEC(N) requests N+1 payload words plus two private header words; negative N or no fitting block gives zero. First fit; split only when remainder >=3 words, otherwise allocate the whole extent (at least N+1 payload). No arithmetic overflow guard for N+3; caller keeps request representable. Memory is not promised zero-filled. FREEVEC(0) no-op; nonzero must be exact live pointer from this arena. Reinsertion by address and coalescing next then previous adjacent extents. No live-allocation membership validation, double-free/foreign/ABA safety or automatic MVS allocation. Do not make private two-word layout a public ABI.

[Regular reuse fixture](../../../mr10-kit-compiler/tests/00-regression-panel/storage/getvec-reuse.bcpl) verifies same-address reuse in its one controlled sequence (B-A=0, endpoints 11/13), not general guarantee of same address. [JOB 9550](../../../mr10-kit-compiler/tests/11-getvec-freevec/acceptance-20261104.md) is separately accepted initial golden-output evidence. Other arena exact-fit/coalescing/exhaustion research and coroutine denial tests remain their own scoped evidence; no new allocator safety claims.
