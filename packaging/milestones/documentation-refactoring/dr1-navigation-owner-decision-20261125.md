# DR.1 — Documentation navigation: owner decision

**Project:** BCPL for MVS 3.8 Reconstruction  
**Milestone:** Documentation Refactoring  
**March:** DR.1 — Architecture and Outlines (IN PROGRESS)  
**Date:** 25 November 2026 EST  
**Status:** Owner-approved navigation direction.

The owner agreed that docs/README.md shall present the manual catalog primarily by the four Diátaxis types (Tutorials, How-to Guides, Explanations and References), with a secondary index by subject. Both views link to the same canonical manuals; neither duplicates their content. Readers may find information according to their task or subject of interest.

## Application

The root README remains the project and public-release entry point. The documentation catalog links the product and project manuals in their approved directories. Provide access to current release-specific documentation and the existing project records, historical material and provenance through their respective indexes. Keep source-local navigation and executable dependencies intact. Use descriptive chapter headings and relative links; long manuals may have a short chapter index. Detailed subject labels and link targets will be established from the approved catalog and actual manual paths. Do not publish links to nonexistent manuals or create empty placeholders.

This decision complements the [manual catalog](dr1-manual-catalog-owner-decisions-20261125.md), [normative reference authority](dr1-reference-authority-owner-decision-20261125.md), [directory organization](dr1-directory-organization-owner-decision-20261125.md) and [canonical Markdown format](dr1-canonical-markdown-owner-decision-20261125.md) decisions. The remaining design work concerns detailed chapter outlines, migration, reconciliation and formal DR.1 acceptance.

No catalog implementation, manual creation, relocation, deletion, release activity or MVS operation has been performed. The DR.0 dependency qualification remains in effect.
