## MR10 Kit Compiler

Retain the compile (SYNI/TRNI/BLIBI/ICLIB, SYSIN -> textual OCODE), generate (CGI/BLIBI/ICLIB, OCODE -> INTCODE), and execute (ordered application INTCODE plus required library decks) stages. OCODE/INTCODE are FB80 text, not IBM object decks. Installed suite JCL stages phase members into sequential datasets to avoid the observed end-of-member issue. Distinguish tracked host-driver decks from installed phase members, and host-selected interpreter source from installed ICINT19.

Historical SYN START obtains the optional first OPTIONS record, echoing it and stopping on newline/EOF; absent selects defaults. The exact echo of L's numeric value is produced by WRITEN, with TERMINATOR reprocessed, not a byte-for-byte original record echo. Defaults tree 5500 words, save space 2, indexed flags false, source/lexer tracing false, identity character conversion, REPORTMAX 20. CGI does not read OPTIONS. Preserve P token-debug, T tree, C suppress OCODE, M MAPSTORE, N suppress GET, A character-literal conversion, S top-level source listing, E lexer trace, L decimal tree size and 3 save-space spelling. The mutable flag index and permissive unknown characters are source behavior, not validation or accepted arbitrary option grammar. Neither historical deck equivalence nor independently tested every switch follows.

Accepted nondefault behavior: L12000 is the tracked bootstrap compilation option (actual CAMBBLD uses it); JOB 9921 verifies L6000N echo and deliberately missing GET suppression, not measured allocation size. JOB 9920 verifies two nested named GET inputs and return at EOF/period (17 5 20 42). Maintain valid allocated uppercase 1–8-character DD preconditions and separate driver uppercase normalization from interpreter lookup. The source VEC 10 GET stack stores three words per frame but has no MR10 extent guard; missing DD uses report 96 and ordinary recovery after SOURCESTREAM changed. No arbitrary nesting, oversized DD, duplicate-open or missing-input safety promise. Historical error 97 and REPORTCOUNT>REPORTMAX are source-derived, not exact diagnostic-recovery certification.

The current MR10 driver supports ASCII input records of at most 80 columns and additional BCPL modules in +PATH order; --dd binds named inputs to compile and final run, rejects reserved and duplicate names. Host flags are not compiler options. Require zero ICINT completion for each successful compile/generate phase and independent application CODE/semantic oracle. The generic pipeline validator checks at least 2*n+1 interpreted entries and checks the compile/generate codes; it is not by itself an exact final RUN oracle. The regression harness's additional receipt and result checks remain necessary.

No general --dd; four supplied headers only. The normal retrieval uses full printer; optional BCPL_PRINTER_WINDOW_TRIAL=1 is explicit trial, not the accepted default. Do not change tool behavior as part of this transfer.

Compiler driver requires submit-and-wait max_rc=0 and exactly one interpreted completion-code match of zero, then last matching begin marker, following end marker, nonempty trimmed text. This does not verify complete valid assembler units or binary records, no physical DD attribution guarantee. Separate IFOX/IEWL/GO and exact oracle remain necessary; e.g. case 192 additionally checks two complete units. The generic driver is not an application-execution command and driver RC0 is not compiler/assembler/linker/runtime semantic certification. Specific host CLI/preview/trial behaviors remain independently reviewable in Project Tools.
