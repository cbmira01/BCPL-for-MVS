## Actual TA.4 acceptance gates

1. **Distributed executable and reproducible rebuild.**
   The installed `MR10KIT.LOAD(ICINT19)` works
   independently. Verify the distributed
   `MR10KIT.ASM(ICINT19)`, `MR10KIT.OBJ(ICINT19)`,
   `MR10KIT.JCL(IC19BLD)`, and appropriate source/linkage
   using actual **IFOX/IEWL/MVS execution** and isolated
   build outputs. Do not replace or corrupt accepted load modules.
2. **Eleven MR10 language demonstrations.**
   Run actual MVS compile/generate/execute verification
   through `MR10KIT.JCL(MRLANGDM)` and the
   distributed `MR10KIT.LANGDEMO` source members.
   Require all **11 accepted cases**; record exact MVS
   job, utility steps, interpreted completion codes and outputs.
3. **Seventeen BCPL demonstrations.**
   Execute the exact **17-case** canonical selection from
   `MR10KIT.JCL(MRBCDEMO)` and distributed
   `MR10KIT.BCPLDEMO` sources, including any data inputs.
   The source PDS contains more than 17 members;
   selection must be confirmed against actual JCL,
   not guessed from directory cardinality.
4. **Twelve-case MRREGRES automatic semantic acceptance.**
   Preserve printed literal EXP:, calculated RP:, TEST: and
   interpreted CODE=0. Independently compare all twelve cases
   from accepted JOB 9369 against the tracked goldens and seal
   per-case automatic PASS/FAIL evidence. Reject any deviation.
   The 23 November owner decision removes human verdicts and
   SIGN prompts. Do not replay accepted MVS operations.
   Keep WSL RP:/CODE= automated checks unchanged.

**TA.4 PASS requires all four gates.** MVS JES RC0000
is not, by itself, semantic PASS. The full 12-case
`MRREGRES` panel is a distinct requirement from the
single-case TA.3 SCALVEC smoke test.
