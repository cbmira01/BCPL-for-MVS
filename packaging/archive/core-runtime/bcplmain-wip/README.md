# Historical BCPLMAIN-WIP modularization and runtime probes

This archive preserves dated BCPLMAIN, BCPLMEM, APTOVEC, runtime-global
and MVS observations from the earlier monolithic-runtime extraction work.
They contain incremental checkpoints and provisional claims; the
[active Core Runtime sources](../../../../bootstrap-toolchain/asm/README.md)
and [runtime contract](../../../architecture/runtime-contract-v1.md) remain
authoritative for the current reconstructed system.

The four historical assembler fragments remain executable test inputs at
[`asm/bcplmain-wip/`](../../../../bootstrap-toolchain/asm/bcplmain-wip/README.md).
The historical monolithic assembler remains
[`asm/history/bcplmain-wip.asm`](../../../../bootstrap-toolchain/asm/history/bcplmain-wip.asm).
