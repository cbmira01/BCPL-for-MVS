# Cambridge bootstrap native-codegen evidence

The [native System/370 code-generation checkpoint](native-codegen-checkpoint.md)
preserves observed compiler execution, target/host byte boundaries, generated
System/370 ABI, global-vector displacements and system-vector entry use.

This checkpoint is **historical evidence**, not the authoritative compiler
build procedure or a complete native ABI specification. See the
[current bootstrap guide](../../../bootstrap-toolchain/bootstrap-cambridge/README.md)
and [runtime contract](../../architecture/runtime-contract-v1.md).
