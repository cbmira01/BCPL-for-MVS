# BCPL Standard Library (BSL)

This is the planned top-level home for Cambridge-distributed, optional general-purpose BCPL modules. No BSL implementation, API, object module, PDS member, or milestone is approved or established by this directory.

See `packaging/architecture/bsl-scope-and-module-design-20261103.md` and `packaging/architecture/runtime-and-library-nomenclature.md`. System Extension dispatchers and their direct wrappers belong to `system-extensions/`, not here.
