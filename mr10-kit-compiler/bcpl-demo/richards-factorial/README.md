# Richards factorial demo

A small recursive example from the early compiler work. It prints factorials from 1 through 10. The final value is 3,628,800.

| File | Use |
| --- | --- |
| `bcpl-demo/richards-factorial/richards-factorial.bcpl` | Readable demo |
| `tests/03-compile-richards-factorial/richards-factorial-test.bcpl` | Historical compiler probe |

Run all demos with `tools/mr10/run-demo-suite` from the repository root.
