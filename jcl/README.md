# JCL

This directory holds checked-in JCL that is useful as a reusable example, a diagnostic job, or a historical milestone. Most current build/test JCL is generated by the host tools and written to `workarea/` or submitted directly.

Current files include:

- `hello-world-heavy.jcl` — detailed IFOX assemble/link/run example;
- `dump-jes2-parameters.jcl` and `list-parmlib-members.jcl` — MVS/JES inspection jobs;
- `icintv12-honors-thesis.jcl`, `icintv13-honors-thesis.jcl`, and `icintv13-mapstore.jcl` — retained milestone decks from ICINT development.

The ICINT milestone decks are evidence of earlier reconstruction stages. They should not be treated as the current way to build the promoted interpreter; use `tools/current-icint`, `tools/run-intcode`, or `tools/compile-and-run` instead.

For new assembler work, generate JCL with:

```sh
tools/make-asm-job asm/program.asm --output-dir jcl --listing heavy
```

For BCPL/INTCODE work, prefer the higher-level host tools. They generate explicit phase banners and data-set wiring while keeping the job reproducible.

Native-target JCL will grow as the surviving historical System/370 code generator is brought into the pipeline and its assembler output is validated with IFOX and the linkage editor.
